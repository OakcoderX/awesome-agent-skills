# External A/B Tester Feedback

This file exists to support a public feedback thread for **Socratic Story Cartographer**.

If you already use AI to review a screenplay, novel, treatment, or series outline, please run the published comparison protocol:

- [Skill vs prompt A/B protocol](./AB-TEST.md)

Then comment on the pull request that introduced this file with the smallest useful result you can share.

Useful reports include:

- the kind of material you tested
- model / harness used
- whether both runs saw the same material in fresh sessions
- where the strong baseline prompt did better
- where the Skill did better
- any unsupported diagnosis or missed source coverage
- whether either approach changed its diagnosis under counter-evidence
- whether the proposed fix introduced regression risk
- whether the final revision handoff was actually usable

A tie or a failure is useful evidence. Please do not optimize the report to make the Skill look good.

If you cannot share the text itself, a concise behavioral comparison is enough.
